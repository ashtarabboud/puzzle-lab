# Puzzle Lab

A personal puzzle arcade with ten games, a daily ten-puzzle quiz, adaptive difficulty and detailed statistics.
It runs entirely on the phone and works offline once installed.

**Install on iPhone:** open the site in Safari → Share → Add to Home Screen.

Games: Password · The Island · Word Bridges · Algebra Arcade · Loop Logic · Word Detective · Shape Shift · Balance · Reverse Engineer · Word Links.

Built with plain JavaScript (no framework) so the engines can later be reused in a native wrapper.
Word data: SCOWL word lists, WordNet 3.1 (Princeton University), CMU Pronouncing Dictionary. Fonts: Atkinson Hyperlegible, Bricolage Grotesque, JetBrains Mono (SIL OFL).
